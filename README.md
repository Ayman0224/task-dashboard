# Task Dashboard

A full-stack task management dashboard built with React, Node.js, Express, and SQLite.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed or pending
- Search tasks
- Filter tasks by status
- Overdue task tracking
- Responsive design
- Mobile sidebar navigation
- Dark and Light mode
- Loading and error handling

## Technologies

### Frontend
- React
- JavaScript
- CSS

### Backend
- Node.js
- Express.js

### Database
- SQLite

## How to Run

### Backend
runs on : http://localhost:5050

cd backend
node index.js

cd frontend
npm install
npm run dev
