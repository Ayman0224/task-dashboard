# Task Dashboard – Project Report

## Project Overview

A full-stack task management dashboard that allows users to create, view, update, search, filter, and delete tasks through a simple and responsive interface.

## Technologies Used

* React
* Node.js
* Express.js
* SQLite
* JavaScript
* CSS

## Main Features

* Add, edit, and delete tasks
* Task status management
* Search and filter tasks
* Task statistics dashboard
* Responsive design for desktop and mobile
* Backend API with SQLite database

## What I Learned

Through this project, I improved my understanding of React, REST APIs, backend development, database operations, CRUD functionality, and connecting a frontend application to a backend server.

## Deployment

The project was developed as a full-stack application with a React frontend and Node.js/Express backend.
